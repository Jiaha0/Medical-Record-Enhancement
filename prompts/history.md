# 当前任务：病史生成

医生会给你零散的要点（可能是关键词、短句、口语、缩写，顺序混乱）。请把它们整理成连贯、规范的病史文字。

## 输出结构

按下列顺序分段，每段用 `**段名：**` 开头，段内写成通顺的完整句子（不是罗列关键词）：

- **主诉：** 仅当医生提供了主要症状和时间时才写，格式为"症状+持续时间"，不超过20字。没有就省略整段。
- **现病史：** 本次就诊相关的起病时间、诱因、症状演变、诊治经过、目前情况。按时间顺序叙述。
- **既往史：** 依次写：慢性病史（病名、发现时间、最高值/严重程度、用药名称+剂量+频次、控制情况）→ 传染病史 → 手术外伤史（年份+手术名称）→ 输血史 → 药物/食物过敏史 → 预防接种史。
- **个人史：** 吸烟、饮酒、职业、疫区接触等。
- **婚育史：** 婚姻状况、孕产次（G P）、分娩方式。
- **月经史：** 女性患者且有信息时写，如初潮年龄、周期、绝经情况。
- **家族史：** 家族中相关疾病。

## 缺失信息的处理

- 某一段医生**完全没有**提供任何信息：整段只写"**段名：** 未提及。"（主诉除外，主诉直接省略）。
- 某一段**有部分信息**：只写已有的信息，**不要逐项罗列缺了什么**。错误示范："性质、部位、持续时间及伴随症状未提及""高血压、冠心病等其他慢性病史未提及""职业、疫区接触史未提及"。
- 既往史例外：既往史固定按"疾病史 → 传染病史 → 手术外伤史 → 输血史 → 过敏史 → 预防接种史"六项写，没有信息的项目统一写"××史未提及"，每项最多一句。
- **不要**自行写"否认肝炎、结核等传染病史""否认药物过敏史"这类否认句——除非医生明确写了"否认……"或"无……"。
- 医生明确说"无"/"否认"的，写成规范否认句式，如"否认药物、食物过敏史。"
- 男性患者省略"月经史"整段；"婚育史"没有信息时写"未提及"。
- 现病史只写医生给出的经过，**不要**补"无明显诱因""突发""无意中发现""遂来我院就诊"等医生没说过的话。

## 时间表达

- 保留医生给出的时间形式："2001年"就写"2001年"，"10年"写"10年前"或"病史10年"。
- 不要根据当前日期把"10年前"换算成具体年份。

## 示例

输入：
```
女 44岁 左乳肿物3月 无痛 渐大 外院B超BI-RADS 4c 穿刺浸润性导管癌
高血压10年 最高180/110 氨氯地平5mg 一天一次 控制在130/80左右
2001年剖宫产
青霉素过敏
不抽烟不喝酒
已婚 G2P1
```

输出：
**主诉：** 发现左乳肿物3个月。

**现病史：** 患者3个月前发现左乳肿物，无疼痛，肿物逐渐增大。于外院行乳腺B超检查，提示BI-RADS 4c类；行穿刺活检，病理示浸润性导管癌。

**既往史：** 高血压病史10年，血压最高达180/110 mmHg，规律口服氨氯地平5 mg，每日1次，血压控制在130/80 mmHg左右。传染病史未提及。2001年行剖宫产术。输血史未提及。有青霉素过敏史。预防接种史未提及。

**个人史：** 无吸烟、饮酒史。

**婚育史：** 已婚，G2P1，2001年剖宫产1次。

**月经史：** 未提及。

**家族史：** 未提及。

再一个示例（信息很少时，注意不要补充、不要罗列缺项）：

输入：
```
男 65岁 胸痛2小时 既往糖尿病5年 二甲双胍0.5 tid
```

输出：
**主诉：** 胸痛2小时。

**现病史：** 患者2小时前出现胸痛。

**既往史：** 糖尿病病史5年，口服二甲双胍0.5 tid。传染病史未提及。手术外伤史未提及。输血史未提及。过敏史未提及。预防接种史未提及。

**个人史：** 未提及。

**婚育史：** 未提及。

**家族史：** 未提及。
