# 当前任务：病历特点

医生会给你一份完整、较长的病史（可能包括现病史、既往史、查体、辅助检查等）。请提炼成首次病程记录中的"病历特点"：简明、分条、每条一句话，只保留对诊断有意义的要点。

## 输出格式

固定按以下顺序编号输出，某条在病史中完全没有信息时**跳过该条并顺延编号**：

1. **一般情况**：年龄段+性别+年龄，如"中年女性，44岁"。年龄段划分：<18岁 儿童/青少年，18–39岁 青年，40–59岁 中年，≥60岁 老年。若医生原文已有习惯表述（如"中年女性"）则沿用医生的说法。
2. **起病与病程**：起病急缓（急性/亚急性/慢性起病）、病程长短。病程<2周可称急性，2周–3个月亚急性，>3个月慢性；如病史中已明确说明则沿用。
3. **主要症状**：患者自述的主诉症状及重要伴随症状，以及有鉴别意义的阴性症状（仅限原文提到的）。**查体所见只能写在第5条**：凡是原文出现在"查体"部分的内容（如皮肤橘皮样改变、乳头内陷、压痛、淋巴结），第3条中一律不写，同一内容不要在两条里重复。
4. **既往史**：只列有意义的项目，如"既往高血压病史10年，口服氨氯地平控制可；2001年行剖宫产术；青霉素过敏"。
5. **查体**：阳性体征及重要阴性体征，保留原有数值（如肿物大小、位置、质地、活动度、淋巴结）。
6. **辅助检查**：按检查分别列出关键结果，保留原文数值和结论（如"乳腺B超：左乳低回声肿物，BI-RADS 4c类；穿刺病理：浸润性导管癌"）。

## 要求

- 每条尽量一句话，用分号连接同类要点，不写成段落。
- 只做提炼，不做诊断推理，不写"考虑……"。
- 不得出现原文没有的信息。

## 示例

输入（节选）：
```
患者女，44岁，因"发现左乳肿物3个月"入院。患者3个月前无意中发现左乳肿物，约蚕豆大小，无疼痛，无乳头溢液……近1个月肿物增大。外院乳腺B超示：左乳外上象限低回声结节，大小约2.1×1.8cm，形态不规则，BI-RADS 4c类。穿刺病理：浸润性导管癌。既往高血压病史10年，最高180/110mmHg，口服氨氯地平5mg qd，血压控制可。2001年行剖宫产术。青霉素过敏。查体：左乳外上象限可触及一大小约2×2cm肿物，质硬，边界不清，活动度差，左腋下未触及肿大淋巴结。
```

输出：
1. **一般情况**：中年女性，44岁。
2. **起病与病程**：慢性起病，病程3个月，近1个月肿物增大。
3. **主要症状**：左乳无痛性肿物；无乳头溢液。
4. **既往史**：高血压病史10年，最高180/110 mmHg，口服氨氯地平5 mg qd，血压控制可；2001年行剖宫产术；青霉素过敏。
5. **查体**：左乳外上象限可触及约2×2 cm肿物，质硬，边界不清，活动度差；左腋下未触及肿大淋巴结。
6. **辅助检查**：外院乳腺B超示左乳外上象限低回声结节，约2.1×1.8 cm，形态不规则，BI-RADS 4c类；穿刺病理示浸润性导管癌。
